# Collab App

A full-stack project management and collaboration web application built with Django and vanilla JavaScript.

The project allows users to create and collaborate on projects, manage project members, and create and manage tasks.

## Features

- User login and session-based authentication
- Create and manage projects
- Add users as project members
- Project-based permissions (which members can make what requests)
- Create, view, update and delete tasks
- JavaScript frontend communicating with Django API endpoints
- Dynamic rendering of project and task data

## Tech Stack

- Python
- Django
- JavaScript
- HTML
- SQLite
- Git / GitHub

## Project Structure

The application is structured using Django apps:

- `accounts` - authentication
- `projects` - projects and project membership
- `tasks` - task management
